# FOK Academy Landing Page

A responsive single-page landing page inspired by the supplied FOK Academy logos.

## Files
- `index.html` — page structure and editable copy
- `styles.css` — complete responsive design system
- `script.js` — FAQ accordion + mobile navigation
- `assets/` — supplied FOK Academy logo variants

## Quick start
Open `index.html` directly in a browser, or serve the folder with any static server.

## Customize first
1. Replace the instructor placeholder with the real instructor photo/name.
2. Replace placeholder student testimonials with real, permissioned testimonials.
3. Replace course price and refund policy with the actual offer.
4. Connect every CTA to the real checkout/payment URL.
5. Add real Amazon Seller Central screenshots/results where available.


## 10-minute introductory offer

The updated template starts a 10-minute browser-session countdown:
- Before expiry: ₹499
- After expiry: ₹899

The visible price, CTA and countdown update automatically when the timer reaches zero.

**Important for production:** the JavaScript timer is only a front-end experience. If the ₹499 price is a real offer, enforce the price/deadline in your payment/checkout system too. Otherwise a visitor could bypass the front-end timer or refresh/open another browser.
